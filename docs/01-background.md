# 一、背景、目的与方案选择

## 背景

本项目对象是一台康佳 B55U 老款 Android 智能电视。硬件仍可使用，但内置平台服务较多、系统版本旧、可用数据分区容量较小。要求：不更换主板、购买新盒子或清空系统，而是在**维持现有电视日常功能**的前提下，减少广告、推广、冗余入口及不必要后台驻留。

## 为什么先做 Root 再做精简

普通设置页能卸载的应用有限；Android 中一些预装应用、厂商服务或系统组件需要更高权限查看启动配置、应用状态与进程。**Root 是管理手段，不是优化效果本身。**

目标分三层：

- **可管理**：在 Windows 上稳定连接电视和审计安装包、内存、进程。
- **可持续**：通过本机已有开机钩子，使 Root ADB 能在正常重启后恢复。
- **可回滚**：明确白名单、保护核心包；每一步都有状态记录及恢复方法。

## 不做什么

不直接修改内核、Boot 镜像或声称安装 Magisk；不证明 TVOS 服务对所有固件都一样；不修改遥控器/电视核心 native 服务。
