# 九、还需要补证的内容

这个项目的目标是让新手**真正能重复实验**，不是仅让别人复制几条成功后的 ADB 命令。因此以下事项必须公开标识：

1. **首提权入口复现未完成**：需回收当日可执行调用程序的完整命令行、参数、返回值、许可证、适用固件及 SHA-256；不能凭“以前提过一次权”推测出可用命令。
2. **ADB 公钥授权步骤未单独成文**：需记录是否通过电视弹窗、原厂 Root 命令执行接口还是其他方式把 PC 公钥写入电视，以及正确文件权限。不要公开真正密钥。
3. **开机回滚尚未独立实测**：有原厂备份与回滚设计，但缺少完整“回滚—重启—检查”的新证据。故参考脚本只供理解。
4. **`com.konka.systemadvert` 恢复后状态需更新**：2026-10-27 22:10 快照仍显示 disabled，与后来用户说“已经恢复”是不同时间点，需再次导出 `pm list packages -d` 证实。
5. **精简效果仍待量化**：多轮开机、PSS、CPU、磁盘容量及遥控/视频功能验收。
6. **其他机型兼容性未知**：尤其是 init 钩子、TvManager 服务、属性和包名。

所有待补项都不应为了宣传“完整教程”而虚构。
