### Root 验证

- `B55U_service_report.txt`、`B55U_tvos_id.txt`：在本机获得 `uid=0(root)`。
- `B55U_PERSIST_RESULT.txt`：存在真实 `flash_recovery` 钩子且成功写入启动脚本，最后 `/system` 重新只读。
- 重启后 Windows ADB 返回 `uid=0(root)`；电视 `/data/local/tmp/B55U_bootroot.log` 含 `ADB_ROOT_SETTING 1`、`TCP_SETTING 5555` 和完成标记。

### 如何才算性能改善

至少要固定冷启动路径、开机到桌面时间、空闲 3–5 分钟后多次测量 RAM/PSS、CPU 占用、播放器响应、`/data` 空间，并进行多轮重启，才能进一步判断。**目前尚未做足以上对照实验，因此本仓库不写“提速 X%”或“释放 X MB”。**
